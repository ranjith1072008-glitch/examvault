# ExamVault

An open-source exam notes hub for school and college students.

**Live preview:** https://examnotes-helper--7dgqifuq.preview.emergentagent.com/

## Features
- Search study guides by department and year
- AI study summaries and practice questions powered by Claude
- Sample study guides to try right away
- Open uploads, and people can delete only their own files (in progress)

## Status
Built with Emergent App Builder. The full source code will be added here once it is exported.
